# 配方中控台

Streamlit 配方工具，包含：

- V、Q、SE、額外母液比例與濃度可調
- 母液比例及濃度採直接數值輸入
- G 後添加
- 額外添加劑按最終目標總量占比計算
- D7 固定為 Q × 0.003
- 品管濃度不足時的補加量計算
- 所有用量顯示至小數點後 2 位
- 無成本計算、無圓餅圖

## 額外添加劑與 G

```text
額外添加劑量 = 最終目標總量 × 額外添加劑占比
母液＋水基準 = (最終目標總量 - 額外添加劑量) ÷ (1 + G比例)
G量 = 母液＋水基準 × G比例
```

## 品管補加

```text
補加量
= 目前批次量 × (目標濃度 - 目前濃度)
  ÷ (補加原料濃度 - 目標濃度)
```

此公式會考慮補加後總量增加的稀釋效果。

## 配方名稱、固成分與比重

新版可輸入配方名稱，並在畫面、紀錄、文字配方、CSV 與 PDF 中顯示。

### 固成分

- V、Q、SE、額外母液：採輸入的固成分／母液濃度
- G（葡萄糖酸鈉）：100%
- 額外添加劑：預設 100%，可調整
- 水：0%
- D7：不納入

```text
配方固成分
= 各材料固體重量合計 ÷ 主配方總量 × 100%
```

### 比重估算

固定比重：

- V：1.078
- Q：1.118
- SE：1.078
- G（葡萄糖酸鈉）：1.800
- 水：1.000

額外母液、額外添加劑與 D7 暫不納入。網站會顯示本次比重估算的配方質量涵蓋率。

```text
估算比重
= 已知比重材料總重量
  ÷ Σ(各材料重量 ÷ 各材料比重)
```

此方法假設各成分體積可加成，適合作為配方估算值；正式品管仍建議以實測比重為準。


## 理論估算 pH

固定原料 pH：

- V：2.6
- Q：3.6
- SE：3.9
- 水：7.0

目前僅納入 V、Q、SE 與水。G、額外母液、額外添加劑及 D7 暫不納入。

```text
混合 [H⁺]
= Σ(10^(-pH) × 原料估算體積)
  ÷ 已知原料估算總體積

估算 pH = -log10(混合 [H⁺])
```

網站會顯示 pH 計算涵蓋率。此結果未考慮緩衝作用、酸鹼反應與活度係數，只能作為理論參考；正式品管仍應以 pH 計實測。
