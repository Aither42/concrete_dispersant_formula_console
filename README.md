# 配方中控台

Streamlit 配方工具，包含：

- V、Q、SE、額外母液比例與濃度可調
- 母液比例及濃度採直接數值輸入
- G 後添加
- 額外添加劑按最終目標總量占比計算
- D7 固定為 Q × 0.003
- 品管濃度不足時的補加量計算
- 所有用量顯示至小數點後 2 位
- 無成本計算、無圓餅圖

## 額外添加劑與 G

```text
額外添加劑量 = 最終目標總量 × 額外添加劑占比
母液＋水基準 = (最終目標總量 - 額外添加劑量) ÷ (1 + G比例)
G量 = 母液＋水基準 × G比例
```

## 品管補加

```text
補加量
= 目前批次量 × (目標濃度 - 目前濃度)
  ÷ (補加原料濃度 - 目標濃度)
```

此公式會考慮補加後總量增加的稀釋效果。


## 配方名稱、固成分與比重

新版可輸入配方名稱，並在畫面、紀錄、文字配方、CSV 與 PDF 中顯示。

### 固成分

- V、Q、SE、額外母液：採輸入的固成分／母液濃度
- G（葡萄糖酸鈉）：100%
- 額外添加劑：預設 100%，可調整
- 水：0%
- D7：不納入

```text
配方固成分
= 各材料固體重量合計 ÷ 主配方總量 × 100%
```

### 比重估算

固定比重：

- V：1.078
- Q：1.118
- SE：1.078
- G（葡萄糖酸鈉）：1.800
- 水：1.000

額外母液、額外添加劑與 D7 暫不納入。網站會顯示本次比重估算的配方質量涵蓋率。

```text
估算比重
= 已知比重材料總重量
  ÷ Σ(各材料重量 ÷ 各材料比重)
```

此方法假設各成分體積可加成，適合作為配方估算值；正式品管仍建議以實測比重為準。


## 反推配方名稱

獨立的「反推配方」頁面可輸入 V、Q、SE、G 與水的實際公斤數，
以 V、Q、SE 與水的合計作為配製基準，反推出輸入百分比。

預設母液濃度為 V 40%、Q 60%、SE 40%，也可在進階設定中調整。

```text
V輸入%  = V用量 × V母液濃度 ÷ 配製基準
Q輸入%  = Q用量 × Q母液濃度 ÷ 配製基準
SE輸入% = SE用量 × SE母液濃度 ÷ 配製基準
G輸入%  = G用量 ÷ 配製基準 × 100
```

命名採四捨五入（0.5 進位）：

```text
A = V數字 + Q數字
B = SE數字
C = G數字
名稱 = ABC(VＤQＥ)
```

例如 V=8、Q=1、SE=5、G=6，名稱為 `956(V8Q1)`。


## 配方代碼快速輸入

欄位名稱依序為 `V＋Q`、`SE`、`G`，後面再輸入 V、Q。

當 V 與 Q 的合計小於 V＋Q 欄位時，V、Q 視為相對比例，
系統會按原比例放大到指定的 V＋Q 總值。

例如 V＋Q=10、V=8、Q=1：

```text
V = 8 / (8 + 1) × 10 = 8.8889%
Q = 1 / (8 + 1) × 10 = 1.1111%
配方名稱 = 1046(V8Q1)
```

若 V＋Q=9、V=8、Q=1，則直接採用 V=8%、Q=1%。
若 V、Q 合計高於 V＋Q 欄位，系統不會自動縮小，會直接採用輸入值並顯示提醒。
